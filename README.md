# Análisis de venta · Comparativo mensual de ventas

🔗 **Ver en línea:** https://inversionesverdelimon-jr.github.io/analisis-de-venta/

Herramienta web para comparar ventas mensuales entre años a partir de archivos **Excel (.xlsx/.xls), CSV o PDF**.

- Lee diarios contables (débito/crédito por cuenta PUC), listados de facturas o resúmenes mensuales.
- Calcula ventas netas (ventas − devoluciones) por mes y compara hasta 4 años.
- Valida coherencia: totales, duplicados, fechas futuras, meses faltantes y valores atípicos.
- Top 20 de clientes frente al mismo periodo del año anterior.
- Exporta los resultados como CSV para Excel.

Los archivos se procesan solo en el navegador; no se envían a ningún servidor.
